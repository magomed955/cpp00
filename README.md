# CPP Module 00

CPP Module 00 is the first project in the C++ modules of the 42 curriculum, introducing the fundamentals of object-oriented programming. The project focuses on basic C++ syntax, namespaces, classes, member functions, input/output streams, and the initialization of objects. Through practical exercises, it builds a foundation in C++ programming and the transition from procedural programming in C to object-oriented design.

**Technologies:** C++, Object-Oriented Programming (OOP), Classes, Makefile, Git.
